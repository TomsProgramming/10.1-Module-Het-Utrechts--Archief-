# Planning – Team Oeteldonk

Module 10.1 Het Utrechts Archief: interactieve webapplicatie en CMS bij de tentoonstelling ‘Ontmoet de Oudegracht’.

**Trello-board:** https://trello.com/b/PBKOK9iQ/101-ontmoet-de-oudegracht-team-oeteldonk

Het board is de actuele planning. Elke kaart heeft een deadline, een label en de geschatte tijd. De grotere taken hebben een checklist.
